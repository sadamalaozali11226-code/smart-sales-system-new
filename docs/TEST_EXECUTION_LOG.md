- لذلك لا يجوز استخدام نشر Preview السابق لإجراء معاملة قبل فصل الاتصال والتحقق منه.
- لم تُرسل طلبات إنشاء أو بيع أو شراء أو دفع أو مرتجع، ولم تُجر أي كتابة على أي قاعدة بيانات في العملية 001.

1. التحقق من اتصال المتصفح في المعاينة المحمية، باستخدام وسيلة مصرح بها، والتأكد أن عنوان Supabase الفعلي هو `https://jqedxgdstifezjrtgucw.supabase.co`.

4. إنشاء مستخدم ومؤسسة وفرع وبيانات اصطناعية للاختبار فقط.
