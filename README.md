# نظام المبيعات الذكي

تطبيق ويب عربي لإدارة المبيعات والمخزون والمشتريات وحسابات العملاء والموردين والتقارير المالية، مبني على واجهة عربية وبيئة متعددة المؤسسات والفروع.

## الوظائف

- تسجيل الدخول وإدارة المؤسسة والفروع والأعضاء والأدوار والدعوات.
- إدارة المنتجات وأسعارها وتكلفة المخزون وحركات المخزون والتحويل بين الفروع.
- فواتير البيع والتحصيل الجزئي والآجل ومرتجعات البيع والاستردادات والإلغاء.
- فواتير الشراء ومدفوعات الموردين وتخصيص الدفعات ومرتجعات الشراء.
- المصروفات والتقارير التجارية وتقارير الربحية وتكلفة البضاعة المباعة.
- حماية السجلات المالية من الحذف النهائي عبر واجهات قاعدة البيانات.

## البنية والأمان

- **Vercel + Express:** تقديم صفحات الواجهة والملفات الأمامية المسموح بها فقط.
- **Supabase Auth + PostgreSQL:** المصادقة، وعزل المؤسسات والفروع، وسياسات RLS.
- **RPCs موثقة:** عمليات البيع والمشتريات والمرتجعات والمدفوعات تتم عبر دوال قاعدة البيانات التي تتحقق من العضوية والصلاحيات.
- واجهة المتصفح تستخدم مفتاح Supabase العام فقط؛ لا تضع مفتاح `service_role` في ملفات المتصفح أو HTML.
- مسارات API القديمة معطلة عمدًا، وملفات المستودع وملفات الترحيل غير متاحة عبر خادم الويب.

## التشغيل المحلي

المتطلبات: Node.js 24 أو إصدار متوافق.

```bash
npm install
npm test
npm start
```

يفتح الخادم على `http://localhost:3000` افتراضيًا. يمكن تغيير المنفذ عبر متغير البيئة `PORT`.

تشغّل `npm test` اختبارات HTTP للصفحات والأصول، وتتحقق من تعطيل API القديم، وعدم إتاحة ملفات المستودع، وسلامة صياغة JavaScript.

## النشر

- الفرع الإنتاجي: `main`.
- يجب أن تنجح اختبارات GitHub Actions وأن يصل نشر Vercel إلى `READY` قبل اعتماد أي إصدار.
- صفحة الأرباح المنفصلة: `/profitability.html`.
- واجهات الأعمال القديمة تحت `/api` تُرجع `410` ولا ينبغي إعادة تفعيلها لتجاوز صلاحيات Supabase.

## ملاحظة تشغيلية مهمة

قاعدة الإنتاج الحالية تحتوي على سجل ترحيلات أوسع من ملفات SQL المتاحة في المستودع، ولا تتطابق الأسماء والإصدارات واحدًا بواحد. لذلك فإن **إعادة إنشاء قاعدة Supabase جديدة من مجلد الترحيلات الحالي لم تُعتمد بعد**. التشغيل المستضاف الحالي مدعوم، لكن يجب توحيد خط أساس قاعدة البيانات واختبار الاستعادة قبل تقديم تثبيت مستقل أو الادعاء بإمكانية إعادة بناء قاعدة فارغة بالكامل.

انظر `docs/OPERATIONS.md` لقائمة التحقق التشغيلية قبل فتح التسجيل التجاري على نطاق واسع.
